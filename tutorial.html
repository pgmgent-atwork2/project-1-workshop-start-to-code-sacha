Tutorial: Een Quiz-Site Maken

Quiz

Inleiding

Welkom bij dit tutorial! Vandaag gaan we een interactieve quiz-site maken met behulp van HTML, CSS en JavaScript. Dit project is perfect voor beginners die zich willen vertrouwd maken met de basis van webontwikkeling.

Stap 1: Je Ontwikkelomgeving Voorbereiden

  1. Maak een map voor je project:
    • Maak een map genaamd project1 op je computer.
  2. Maak de basisbestanden:
    • In de map project1, maak een submap genaamd src.
    • In de map src, maak een submap genaamd css.
    • In de map src/css, maak de volgende bestanden: main.css, quiz.css, tutorial.css en variable.css.
    • In de map src, maak een bestand genaamd script.js.
    • In de map project1, maak de bestanden index.html en tutorial.html.
    • Maak een bestand questions.json in de map src.

<!DOCTYPE html>

  • <!DOCTYPE html>: Dit is de declaratie die aangeeft dat dit een HTML5-document is.
  • <head>: Dit is de sectie waarin metadata over het document wordt geplaatst, zoals de karakterset en de titel van de pagina.
  • <title>Quiz</title>: Dit is de titel van de pagina die in de browsertab wordt weergegeven.
  • <link rel="stylesheet" href="src/css/main.css">: Dit koppelt het CSS-bestand aan het HTML-document.

Laten we deze code stap voor stap uitleggen:

  • <body>: Dit is de sectie waarin de inhoud van de pagina wordt geplaatst.
  • <header>: Dit is de header van de pagina, die de titel en een link naar het tutorial bevat.
  • <main>: Dit is de hoofdinhoud van de pagina, die de quiz-elementen bevat.
  • <script src="src/script.js"></script>: Dit koppelt het JavaScript-bestand aan het HTML-document.

Stap 4: Logica Toevoegen met JavaScript

Open src/script.js en voeg de volgende code toe:


// DOM-selectoren
const categorySelect = document.getElementById("categorySelect");
const questionElement = document.getElementById("question");
const choicesElement = document.getElementById("choices");
const resultElement = document.getElementById("result");
const nextBtn = document.getElementById("nextBtn");

// Quiz-status
const quizState = {
  questionsByCategory: {},
  selectedQuestions: [],
  currentQuestion: 0,
  score: 0,
};

// Vragen laden vanuit het JSON-bestand
fetch("src/questions.json")
  .then((res) => res.json())
  .then((data) => {
    quizState.questionsByCategory = data;
  })
  .catch((error) => {
    console.error("Fout bij het laden van de gegevens:", error);
  });

// Functie om de quiz te starten
function startQuiz() {
  const category = categorySelect.value;
  const allQuestions = quizState.questionsByCategory[category];

  if (!allQuestions) {
    alert("Er zijn geen vragen voor deze categorie.");
    return;
  }

  quizState.selectedQuestions = shuffle(allQuestions).slice(0, 5);
  quizState.currentQuestion = 0;
  quizState.score = 0;
  showQuestion();
}

// Vragen willekeurig schudden
const shuffle = (array) => array.sort(() => Math.random() - 0.5);

// Een vraag weergeven
function showQuestion() {
  const { currentQuestion, selectedQuestions } = quizState;
  const q = selectedQuestions[currentQuestion];

  questionElement.textContent = q.question;
  choicesElement.innerHTML = "";

  q.choices.forEach((choice) => {
    const btn = document.createElement("button");
    btn.textContent = choice;
    btn.onclick = () => checkAnswer(choice);
    choicesElement.appendChild(btn);
  });

  resultElement.textContent = "";
  nextBtn.style.display = "none";
}

// Het antwoord van de gebruiker controleren
function checkAnswer(choice) {
  const { currentQuestion, selectedQuestions, score } = quizState;
  const correct = selectedQuestions[currentQuestion].answer;

  if (choice === correct) {
    resultElement.textContent = "Juist! ✅";
    quizState.score = score + 1;
  } else {
    resultElement.textContent = `Fout ❌ (Juist: ${correct})`;
  }

  document.querySelectorAll("#choices button").forEach((btn) => {
    btn.disabled = true;
  });

  nextBtn.style.display = "inline";
}

// Naar de volgende vraag gaan
function nextQuestion() {
  quizState.currentQuestion++;

  if (quizState.currentQuestion < quizState.selectedQuestions.length) {
    showQuestion();
  } else {
    questionElement.textContent = "Quiz klaar!";
    choicesElement.innerHTML = "";
    resultElement.textContent = `Score: ${quizState.score}/${quizState.selectedQuestions.length}`;
    nextBtn.style.display = "none";
  }
}

Laten we deze code stap voor stap uitleggen:

  • const categorySelect = document.getElementById("categorySelect");: Dit selecteert het categorie-selectieelement in het DOM.
  • const questionElement = document.getElementById("question");: Dit selecteert het element waarin de vraag wordt weergegeven.
  • const choicesElement = document.getElementById("choices");: Dit selecteert het element waarin de keuzes worden weergegeven.
  • const resultElement = document.getElementById("result");: Dit selecteert het element waarin het resultaat wordt weergegeven.
  • const nextBtn = document.getElementById("nextBtn");: Dit selecteert de knop voor de volgende vraag.
  • const quizState = { ... };: Dit is een object dat de status van de quiz bijhoudt, zoals de geselecteerde vragen, de huidige vraag en de score.
  • fetch("src/questions.json") ...: Dit laadt de vragen vanuit het JSON-bestand.
  • function startQuiz() { ... }: Dit is de functie die de quiz start.
  • const shuffle = (array) => array.sort(() => Math.random() - 0.5);: Dit is een functie die de vragen willekeurig schudt.
  • function showQuestion() { ... }: Dit is de functie die een vraag weergeeft.
  • function checkAnswer(choice) { ... }: Dit is de functie die het antwoord van de gebruiker controleert.
  • function nextQuestion() { ... }: Dit is de functie die naar de volgende vraag gaat.
