Tutorial: Een Quiz-Site Maken

Quiz

Inleiding

Welkom bij dit tutorial! Vandaag gaan we een interactieve quiz-site maken met behulp van HTML, CSS en JavaScript. Dit project is perfect voor beginners die zich willen vertrouwd maken met de basis van webontwikkeling.

Stap 1: Je Ontwikkelomgeving Voorbereiden

  1. Maak een map voor je project:
    • Maak een map genaamd project1 op je computer.
  2. Maak de basisbestanden:
    • In de map project1, maak een submap genaamd src.
    • In de map src, maak een submap genaamd css.
    • In de map src/css, maak de volgende bestanden: main.css, quiz.css, tutorial.css en variable.css.
    • In de map src, maak een bestand genaamd script.js.
    • In de map project1, maak de bestanden index.html en tutorial.html.
    • Maak een bestand questions.json in de map src.

Stap 2: De HTML-Structuur Maken

Open index.html en voeg de volgende code toe:


<!DOCTYPE html>
<html lang="nl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Quiz</title>
    <link rel="stylesheet" href="src/css/main.css">
</head>
  • <!DOCTYPE html>: Dit is de declaratie die aangeeft dat dit een HTML5-document is.
  • <head>: Dit is de sectie waarin metadata over het document wordt geplaatst, zoals de karakterset en de titel van de pagina.
  • <title>Quiz</title>: Dit is de titel van de pagina die in de browsertab wordt weergegeven.
  • <link rel="stylesheet" href="src/css/main.css">: Dit koppelt het CSS-bestand aan het HTML-document.
            
<body>
    <header class="quiz__header">
        <h1 class="quiz__title">Quiz</h1>
        <a href="tutorial.html" class="quiz__button quiz__button--tutorial">Tutorial</a>
    </header>
    <main class="quiz">
        <div class="quiz__category">
            <label for="categorySelect" class="quiz__label">Kies een categorie:</label>
            <select id="categorySelect" class="quiz__select">
                <option value="coderen">Coderen</option>
                <option value="natuur">Natuur</option>
                <option value="geschiedenis">Geschiedenis</option>
                <option value="sport">Sport</option>
            </select>
        </div>

        <button class="quiz__button quiz__button--start" onclick="startQuiz()">Start Quiz</button>

        <div id="question" class="quiz__question"></div>
        <div id="choices" class="quiz__choices"></div>
        <div id="result" class="quiz__result"></div>

        <button id="nextBtn" class="quiz__button quiz__button--next" style="display:none;" onclick="nextQuestion()">Volgende vraag</button>
    </main>

    <script src="src/script.js"></script>
</body>
</html>

Laten we deze code stap voor stap uitleggen:

  • <body>: Dit is de sectie waarin de inhoud van de pagina wordt geplaatst.
  • <header>: Dit is de header van de pagina, die de titel en een link naar het tutorial bevat.
  • <main>: Dit is de hoofdinhoud van de pagina, die de quiz-elementen bevat.
  • <script src="src/script.js"></script>: Dit koppelt het JavaScript-bestand aan het HTML-document.

Stap 4: Logica Toevoegen met JavaScript

Open src/script.js en voeg de volgende code toe. We gaan deze stap in meerdere delen uitleggen.

Deel 1: DOM-selectoren

We beginnen met het selecteren van de verschillende elementen in onze HTML-structuur. Dit doen we met document.getElementById.

  
  // DOM-selectoren
  const categorySelect = document.getElementById("categorySelect");
  const questionElement = document.getElementById("question");
  const choicesElement = document.getElementById("choices");
  const resultElement = document.getElementById("result");
  const nextBtn = document.getElementById("nextBtn");

Laten we deze code uitleggen:

  • const categorySelect = document.getElementById("categorySelect");: Dit selecteert het categorie-selectieelement in het DOM.
  • const questionElement = document.getElementById("question");: Dit selecteert het element waarin de vraag wordt weergegeven.
  • const choicesElement = document.getElementById("choices");: Dit selecteert het element waarin de keuzes worden weergegeven.
  • const resultElement = document.getElementById("result");: Dit selecteert het element waarin het resultaat wordt weergegeven.
  • const nextBtn = document.getElementById("nextBtn");: Dit selecteert de knop voor de volgende vraag.

Deel 2: Quiz-status

We maken een object quizState om de status van de quiz bij te houden, zoals de geselecteerde vragen, de huidige vraag en de score.

  
  // Quiz-status
  const quizState = {
    questionsByCategory: {},
    selectedQuestions: [],
    currentQuestion: 0,
    score: 0,
  };

Laten we deze code uitleggen:

  • questionsByCategory: Dit bevat alle vragen per categorie.
  • selectedQuestions: Dit bevat de vragen die geselecteerd zijn voor de huidige quiz.
  • currentQuestion: Dit houdt bij welke vraag momenteel wordt getoond.
  • score: Dit houdt de score van de gebruiker bij.

Deel 3: Vragen laden vanuit het JSON-bestand

We gebruiken de fetch API om de vragen te laden vanuit het JSON-bestand.

  
  // Vragen laden vanuit het JSON-bestand
  fetch("src/questions.json")
    .then((res) => res.json())
    .then((data) => {
      quizState.questionsByCategory = data;
    })
    .catch((error) => {
      console.error("Fout bij het laden van de gegevens:", error);
    });

Laten we deze code uitleggen:

  • fetch("src/questions.json"): Dit laadt het JSON-bestand.
  • .then((res) => res.json()): Dit verwerkt de respons en zet deze om naar JSON.
  • .then((data) => { quizState.questionsByCategory = data; }): Dit slaat de vragen op in quizState.
  • .catch((error) => { console.error("Fout bij het laden van de gegevens:", error); }): Dit vangt eventuele fouten op en logt ze in de console.

Deel 4: Functie om de quiz te starten

Deze functie start de quiz door de geselecteerde categorie te controleren en de vragen te laden.

  
  // Functie om de quiz te starten
  function startQuiz() {
    const category = categorySelect.value;
    const allQuestions = quizState.questionsByCategory[category];
  
    if (!allQuestions) {
      alert("Er zijn geen vragen voor deze categorie.");
      return;
    }
  
    quizState.selectedQuestions = shuffle(allQuestions).slice(0, 5);
    quizState.currentQuestion = 0;
    quizState.score = 0;
    showQuestion();
  }

Laten we deze code uitleggen:

  • const category = categorySelect.value;: Dit haalt de geselecteerde categorie op.
  • const allQuestions = quizState.questionsByCategory[category];: Dit haalt alle vragen op voor de geselecteerde categorie.
  • if (!allQuestions) { ... }: Als er geen vragen zijn voor de geselecteerde categorie, dan wordt een alert getoond.
  • quizState.selectedQuestions = shuffle(allQuestions).slice(0, 5);: Dit selecteert 5 willekeurige vragen uit de categorie.
  • quizState.currentQuestion = 0;: Dit stelt de huidige vraag op 0.
  • quizState.score = 0;: Dit stelt de score op 0.
  • showQuestion();: Dit toont de eerste vraag.

Deel 5: Vragen willekeurig schudden

Deze functie schudt de vragen willekeurig.

  
  // Vragen willekeurig schudden
  const shuffle = (array) => array.sort(() => Math.random() - 0.5);

Laten we deze code uitleggen:

  • const shuffle = (array) => array.sort(() => Math.random() - 0.5);: Dit schudt de array willekeurig.

Deel 6: Een vraag weergeven

Deze functie toont een vraag en de bijbehorende keuzes.

  
  // Een vraag weergeven
  function showQuestion() {
    const { currentQuestion, selectedQuestions } = quizState;
    const q = selectedQuestions[currentQuestion];
  
    questionElement.textContent = q.question;
    choicesElement.innerHTML = "";
  
    q.choices.forEach((choice) => {
      const btn = document.createElement("button");
      btn.textContent = choice;
      btn.onclick = () => checkAnswer(choice);
      choicesElement.appendChild(btn);
    });
  
    resultElement.textContent = "";
    nextBtn.style.display = "none";
  }

Laten we deze code uitleggen:

  • const { currentQuestion, selectedQuestions } = quizState;: Dit haalt de huidige vraag en de geselecteerde vragen op uit quizState.
  • const q = selectedQuestions[currentQuestion];: Dit haalt de huidige vraag op.
  • questionElement.textContent = q.question;: Dit stelt de vraagtekst in.
  • choicesElement.innerHTML = "";: Dit maakt de keuzes leeg.
  • q.choices.forEach((choice) => { ... });: Dit loopt door de keuzes heen en voegt ze toe aan het DOM.
  • resultElement.textContent = "";: Dit maakt het resultaat leeg.
  • nextBtn.style.display = "none";: Dit verbergt de "Volgende vraag" knop.

Deel 7: Het antwoord van de gebruiker controleren

Deze functie controleert of het antwoord van de gebruiker juist is.

  
  // Het antwoord van de gebruiker controleren
  function checkAnswer(choice) {
    const { currentQuestion, selectedQuestions, score } = quizState;
    const correct = selectedQuestions[currentQuestion].answer;
  
    if (choice === correct) {
      resultElement.textContent = "Juist! ✅";
      quizState.score = score + 1;
    } else {
      resultElement.textContent = `Fout ❌ (Juist: ${correct})`;
    }
  
    document.querySelectorAll("#choices button").forEach((btn) => {
      btn.disabled = true;
    });
  
    nextBtn.style.display = "inline";
  }

Laten we deze code uitleggen:

  • const { currentQuestion, selectedQuestions, score } = quizState;: Dit haalt de huidige vraag, de geselecteerde vragen en de score op uit quizState.
  • const correct = selectedQuestions[currentQuestion].answer;: Dit haalt het juiste antwoord op.
  • if (choice === correct) { ... }: Als het antwoord juist is, dan wordt het resultaat bijgewerkt en wordt de score verhoogd.
  • document.querySelectorAll("#choices button").forEach((btn) => { btn.disabled = true; });: Dit zet alle keuze-knoppen op disabled.
  • nextBtn.style.display = "inline";: Dit toont de "Volgende vraag" knop.

Deel 8: Naar de volgende vraag gaan

Deze functie gaat naar de volgende vraag of toont het eindresultaat als alle vragen zijn beantwoord.

  
  // Naar de volgende vraag gaan
  function nextQuestion() {
    quizState.currentQuestion++;
  
    if (quizState.currentQuestion < quizState.selectedQuestions.length) {
      showQuestion();
    } else {
      questionElement.textContent = "Quiz klaar!";
      choicesElement.innerHTML = "";
      resultElement.textContent = `Score: ${quizState.score}/${quizState.selectedQuestions.length}`;
      nextBtn.style.display = "none";
    }
  }

Laten we deze code uitleggen:

  • quizState.currentQuestion++;: Dit gaat naar de volgende vraag.
  • if (quizState.currentQuestion < quizState.selectedQuestions.length) { ... }: Als er nog vragen zijn, dan wordt de volgende vraag getoond.
  • questionElement.textContent = "Quiz klaar!";: Als alle vragen zijn beantwoord, dan wordt "Quiz klaar!" getoond.
  • resultElement.textContent = `Score: ${quizState.score}/${quizState.selectedQuestions.length}`;: Dit toont de eindscore.
  • nextBtn.style.display = "none";: Dit verbergt de "Volgende vraag" knop.
